# DevFlow AI

Interactive SaaS developer dashboard built with React, Vite, TypeScript, and Tailwind CSS.

## Features

- **Dashboard** — Live task/note stats, activity feed, AI suggestions, project progress
- **Kanban** — Drag-and-drop between columns (persisted in localStorage)
- **Notes** — Create, edit, delete notes with modal editor (persisted)
- **Snippets** — Dracula-style syntax highlighting, copy + toast
- **Analytics** — Bar chart, category breakdown, contribution heatmap
- **AI Assistant** — Chat with typing animation and suggested prompts
- **Settings** — Profile, accent colors, AI toggles, workspace reset
- **Persistence** — Tasks, notes, settings, and chat history survive page refresh

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Build

```bash
npm run build
```
